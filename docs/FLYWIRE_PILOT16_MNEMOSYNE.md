## Literature review (reviewed October 9, 2026)

This is a specific design response to **negative experiments**, not an assertion that a similar paper validates our own implementation:

1. **Pan, Hahami, Siegelmann & Sompolinsky (August 27, 2026 preprint)**, [*A complementary learning system for continual episodic memory in large language models*](https://www.biorxiv.org/content/10.64898/2026.08.24.746712v1.full). Fast episodic learning assigns separate sparse low-rank traces, an embedding-based competitive gate selects a trace, and replay consolidates into slower shared weights. Importantly, the authors study *fictional-character autobiographical episode streams*; their mechanism stores episodic memory-specific adapters and even uses retrieval-augmented generation, **which Pilot16 explicitly does NOT implement**. Results cannot be transferred directly to a small original-fly masking model.
2. **Jun, Marupudi, Shah & Varma (2025)**, [*A Neural Network Model of Complementary Learning Systems: Pattern Separation and Completion for Continual Learning*](https://arxiv.org/abs/2507.11393). Neural pattern separation and associative completion are complementary operations; their reported Split-MNIST results are from an unrelated task, not Pretorius.
3. **Kapoor, Mackey, Aloimonos & Lin (2025)**, [*HiCL: Hippocampal-Inspired Continual Learning*](https://arxiv.org/abs/2508.16651). Sparse codes, mixture-of-expert routing, replay and consolidation reduce sequential interference. Pilot16 isolates **fixed cue-code separation and error-corrective content learning first**, without adopting or crediting their full model.
4. **Alonso & Krichmar (2024)**, [*A sparse quantized Hopfield network for online-continual memory*](https://www.nature.com/articles/s41467-024-46976-4), *Nature Communications*. Quantized associative codes and local continual updates motivate controlled code capacity tests; not an endorsement of the original one-hop BC01 hash.
5. **Dos Santos et al. (ICML 2024)**, [*Sparse and Structured Hopfield Networks*](https://proceedings.mlr.press/v235/santos24a.html). Associative retrieval margins, sparse structure and capacity are linked mathematically. Pilot16 reports exact CONTENT target-versus-best-alternative margins and does not substitute a success anecdote.
6. **Whole-brain annotation of Drosophila (Nature 2024)**, [*Whole-brain annotation and multi-connectome cell typing*](https://www.nature.com/articles/s41586-024-07686-5): real mushroom-body Kenyon-cell architectures perform sparse expansion and input discrimination. **Pilot16 does NOT isolate anatomically typed FlyWire Kenyon cells**; its source features are still seeded across the original graph. A fixed orthogonal rotation and top-64 sparsification is only a testable *functional analogy*, not a measured reconstruction of mushroom-body cell identity.
7. **Kim et al. (Artificial Intelligence, January 2025)**, [*Open-world continual learning: Unifying novelty detection and continual learning*](https://www.sciencedirect.com/science/article/pii/S0004370224001735). A memory system must detect unfamiliar inputs, not merely return the nearest stored association. Pilot16 evaluates **cue-only internal familiarity** (rather than comparing an output to an external source candidate set) and reports known-positive correct-and-accepted alongside episode-absent false acceptance.
8. **Dorovatas et al. (March 2026 position paper)**, [*Modular Memory is the Key to Continual Learning Agents*](https://arxiv.org/abs/2603.01761). Explicitly distinguishes in-weight and modular external memory. Useful as a design rationale but **no positive experimental memory efficacy** can be inferred from that position paper.

These are references and hypotheses, not empirical validation of this specific system.

## Why Pilots08–15 did not solve autobiographical memory

Previous original publisher-verified complete 139,255-neuron FlyWire-v783 experiments repeatedly identify **0/31** source-original genuinely untrained fourth literal cues, even when the lexical or pretrained MiniLM source input changes. Pilot12 plugged frozen MiniLM into **top-8 feature selection** and original additive 50,920 original directed eligible connections. Even though own-cue active-feature overlap improved, source-novel correct event IDs remained zero. Pilot13 demonstrated early-source memory association loss **15/16→4/16** as 317 records are imprinted. Pilot14 protected old associative weights (β4 **10/16** earliest) but hurt newest associations (**0/16**), while 50,920-scalar non-neural masked matrix learned newest source content and familiar cue IDs better than all original biological-derived synaptic models. The separate Pilot15 fast/slow two-trace design doubles learned scalar memory capacity; initial artificial graph outcome did not establish strong usable recall. No biological-fly-specific associative memory benefit, semantic autobiographical generalization, intrinsic narrative readout or safe absent-memory rejection has yet been demonstrated.

## Mnemosyne, a new causal intervention

Three separable axes are being tested, **not** simultaneously attributed to FlyWire:

**A. Preserve dense pretrained semantic cue geometry.** Reuse exactly the frozen local CPU [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) ONNX model from original Pilot12, revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`, actual source ONNX SHA-256 `6fd5d72fe4589f189f8ebc006442dbb529bb7ce38f8082112682524616046452`. The pinned random 384→256 projection is deterministic and independent of source records. **Do not top-8 sparsify** this 256D source semantic cue for the principal arm; original CONTENT targets remain exactly the original BC01 signed 256D representations (top-32) with source/dedup/hash unchanged. An explicit sparse top-64 **fixed orthogonal feature rotation** is included as an ablation of functional sparse pattern separation; no label-specific learned routing or extra source IDs in model.

**B. Replace additive Hebbian superposition with online prediction-error correction.** Learn a single fixed input→CONTENT 256×256 `W` from each original source literal cue and source-owned BC01 target (three training presentations per source event). `infer(cue)` returns the normalized signed CONTENT vector from `x@W`; it does not retrieve an event record or source story. Error-corrective rule: `prediction = x@W; error = y - prediction`. Recursive covariance update uses `P_0=I/1.0; k=P x/(1+xᵀP x); W+=mask ⊙ (k ⊗ error); P-=k ⊗ P x`. **With a binary support mask, this is MASKED APPROXIMATE RLS, not exact sparse constrained least squares.** Without a support mask it is standard sequential ridge regression, a strong nonneural learned mapping. Extra inverse input covariance `P` occupies **65,536 independent float64 scalar states per model**, which MUST be disclosed along with actual trainable W feature pairs. Re-use prior Pilot10 additive source BC01 as separate previous-method control, plus frozen MiniLM top-8 additive, dense MiniLM masked *SGD error correction* and lexical BC01 + identical residual rule.

**C. Treat original real FlyWire as a causally testable structural support prior, not biology added for decorative branding.** Use exactly the old fixed original pre/post neuron feature populations (seed31, 32 neurons per feature) and count **50,920** original directed neuronal synapse slots in the original 139,255-neuron FlyWire-v783 CSR. Collapse them into a **binary 256 input feature ×256 output feature support mask**: an input→output weight is permitted if **at least one original directed presynaptic-to-postsynaptic neuron edge** supports that feature pair. This collapses anatomical multiplicity, contact weights, neuronal physiology and direction-specific motifs into binary feature-pair presence. **Unlike Pilots08–15 this is NOT the full 15M-edge original network's direct synaptic simulation.** Call it `FlyWire-derived connectivity-constrained associative matrix`, not a reconstructed Drosophila neural memory.

Compare the very same dense MiniLM online residual algorithm over original-derived mask, source original-derived **binary-degree-preserving rewired mask**, an equally feature-pair-count-matched random nonneural mask, and **unmasked 65,536 W scalar nonneural ridge baseline**. These masks need NOT have equal edge weights or fully equal original neuron-level graph statistics, and original versus rewired feature-pair counts could differ after projection: document those counts, prevent any ungrounded graph advantage claim. This is a real-source anatomical structural prior only, not evidence of original fly learning rules.

No test memory names, labels, narrative records, 317-source nearest neighbors or target codebook is ever passed into model inference.

Ten arms: historical original BC01 additive original neural edges; original pinned MiniLM top-8 additive original neural edges; Mnemosyne dense MiniLM masked approximate RLS original-derived feature pair mask; the same rule on rewired-original-derived feature pairs; same rule on independent random support with original-derived feature-pair COUNT; same rule on unrestricted 65,536 independent W scalar nonneural linear matrix; original-derived mask with MiniLM input sparse **64** projected features; original-derived mask with full MiniLM but SGD delta residual update; original-derived mask with dense MiniLM and source-content **deranged wrong target** (the fixed Pilot13 prior 317-event rotation); original derived mask with **dense BC01 lexical** input and same approximate RLS to isolate the effect of pretrained semantic input. All residual models also store 65,536 scalar inverse-covariance `P` and cost must be reported.

## Novelty rejection: distinct from EXTERNAL oracle nearest source

New cue-only model-native familiarity is defined solely from the learned input covariance `F(x)=clip(1−1.0·xᵀPx, 0,1)`. It neither consults source event IDs nor any original CONTENT codebook. At final train cutoff **calibrate its threshold using 62 VALIDATION absent episodes ONLY** to require <=6/62 empirical false accepts; report acceptance among the other 158 non-evaluation TRAIN known probes as a descriptive sanity check. Neither the 159 prior positives nor 71 heldout episode absences nor 31 old unseen fourth cues are used in *model/hyperparameter selection or threshold calibration*. Then report **joint correct-and-accepted** familiar source counts and false-accepted truly episode-absent test cases at the frozen threshold. A small absent false-accept count accompanied by zero correct-and-accepted familiar matches is failure, not success. The original BC01 direct additive and Pilot12 top-8 additive historical controls do not have a native covariance-based novelty gate.

**Important limits:** a pretrained MiniLM encoder is a frozen source-external prior, not semantics learned from original fly circuitry. Familiar literal cues are *trained*, not true test-time paraphrases. Previously used 31 fourth literal source cues are genuinely untrained but were examined across earlier pilots and are therefore **exploratory repeated tests**, not independently protected confirmatory targets. An independently reviewed human-written cue set and new episode-boundary splits require separate prospective Pilot17. No semantic natural language answer generation, narrative memory output, biophysical Drosophila physiology or definitive Pretorius is claimed.

## Predeclared outcomes and decision criteria

1. **Most important:** correct source event top1 among **31 original source fourth cues never presented during training** and their correct CONTENT similarity margin; compare with wrong-source target, random feature-pair mask, rewired feature-pair support and unrestricted linear RLS. Any result above zero is a signal worth testing on genuinely independent authored probes, **not standalone proof**.
2. Joint old vs new cohort same 16 earliest learned and latest 16 newly taught source records. A memory model that retains source IDs but cannot learn the newest events fails. Use identical source event ID lists through stages, include signed correct CONTENT target minus strongest alternative margin and changed trainable W pair count.
3. Known and unknown distinction: **at most 10% validation-absent false accept** from model-native input-only threshold; test correct/accepted source-known and heldout-absent FA **together**. If input novelty alone cannot distinguish ordinary new semantic source cues, record the negative result.
4. **Causal structural test:** Original FlyWire-derived binary feature support must beat random feature support with equal W pair count, and degree-switched source control, before attributing any gain to biological connectivity. Unmasked dense nonneural residual RLS is a necessary strong control; its W storage + input covariance state must be counted against source-constrained models. Masked approximate RLS is NOT guaranteed to beat unmasked ridge, and no retrospective hyperparameter sweep is permitted on these frozen source test records.
5. Measure compute/memory: actual original source→readout edge slots, original distinct allowed feature pairs, initial and final W nonzero pairs, P scalar footprint, exact source 951 cue updates, real v783 CSR hash, revision+model SHA, synthetic vs real provenance.
6. Preserve full raw source per-case JSON and trained W/P/masks, exact SHA-256, experimental protocol and cross-project journal outcomes. Do not claim successful real original-v783 result until publisher v783 verifications, source SHA, original case-matrix integrity and successful full biological experiment check.
