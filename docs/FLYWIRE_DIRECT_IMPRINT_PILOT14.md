# Pilot 14 — Synaptic write protection versus source-memory interference

**Protocol fixed before first original full-v783 measurement.** Status: engineered, CI verification pending. Owner: [Pretorius-Connectome](https://github.com/Azimn/Pretorius-Connectome), research tracker [Issue #17](https://github.com/Azimn/Pretorius-Connectome/issues/17), canonical intellectual chronology [Artificial Life Research Journal](https://github.com/Azimn/Artificial-Life-Research-Journal).

## Why this experiment

[Original whole FlyWire Pilot 13](../results/imprinting/PILOT13_REAL_V783_PROVISIONAL.md) identifies *within-record interference*: the exact first 16 source autobiographical events identified 15/16 correctly after training the first 16 events, but only 4/16 after all 317 source memories. The identical rewired graph control lost 15/16 to 3/16; both deranged target controls identified zero anchors at initial and final learning. The actual original 50,920 eligible source-feature→readout edges saw 73,147 update operations and 28,938 nonzero delta locations after 317 memories, with declining net novel edge occupancy. This establishes that original early event-specific association can be learned before signal is eroded by later source-content learning, but neither the cause nor a remedy has been isolated.

The primary causal question here is **can a simple local usage-dependent reduction of later writing into heavily used existing directed synapses protect earlier content association while retaining the ability to learn newly presented events?** This is a numerical toy metaplasticity hypothesis, **not a biological statement about Drosophila learning**.

No previous memory data, encoder, connectivity array or learned Pilot08–13 checkpoint is changed. Reuse exactly the canonical 450-event reconstructed Pretorius v12 L0 and L1 sources (27 episodes), original source-pinned BC01 256D lexical cue/features and 256D narrative content targets, seed31 episode split (317 trained source events, 62 validation-absent, 71 test-absent), original seed20261008 deterministic training order, three first/middle/last original literal source-cue presentations at numeric learning rate 0.7/3 per memory, fixed presynaptic/postsynaptic populations and *top-8 cue/top-32 content features* for every neural condition.

Original biological-connectivity requirements are exact FlyWire v783 publisher source verification of 139,255 neuron root IDs, 15,091,983 aggregated original directed edges, 54,492,922 integer original synapse contacts, all four original source CSR array SHA-256s and no anatomical changes. Degree-preserving rewiring uses Pilot12's seed73 two-swap per eligible source→readout edge, with the same eligible directed-pair source outdegrees and target indegrees, but **not contact-weighted target incoming strength**.

The original source baseline must reproduce the frozen [Pilot10 learned state](../artifacts/imprinting/checkpoints/pilot10-original-v783-run37869353939.npz), checkpoint SHA-256 fbc2f329993d414cde3ce3a1271a1083098c6513410373e124362045a427c86a and original case JSON SHA ce2d463a72fa58a1e65265cf50f961f9e585610d058b9701d26791e033e7cea8. ## Models and matched resource controls

All seven arms see the exact same original staged source records, 0, 16, 32, 64, 128, 256 and 317 events with 3 original cue presentations each. No test event IDs or narrative texts are available to model inference. Each numerical neural arm is only a fixed signed sparse array of learned synaptic deltas over existing original or rewired directed eligible edges and source-owned local numerical per-edge exposure counters.

- **Original baseline:** original FlyWire directed edges, original Hebbian-like additive update, no protection. Must replay Pilot10.
- **Rewired baseline:** same source learning rule, same feature-neuron population, binary-degree-preserving real FlyWire directed edge target swaps.
- **Original β=1:** local future update attenuation `increment/(1+prior_edge_exposures)`.
- **Original β=4:** same strictly predeclared stronger edge exposure protection, `increment/(1+4*prior_edge_exposures)`.
- **Rewired β=1:** same protection under the binary-degree-switched original graph.
- **Original β=1, shuffled content:** identical β=1 cue presentations but wrong original-content targets rotated by the previously pinned 317-record non-self permutation. Must establish source-content correct pairing matters.
- **Matched-slot non-neural sparse linear:** separate 256×256 signed cue-to-content matrix with exactly **one randomly seeded trainable scalar input/output parameter per original eligible biological synapse slot** (real whole brain: 50,920 of 65,536 possible feature pairs; synthetic uses its own measured slot count). Source-independent seed73 mask, original top8/top32 BC01 input and content and same per-cue rate/cap as other arms. This is **parameter slot COUNT matched**, not anatomical connectivity, contact strength, numeric update norms, edge update event counts or biological computational cost matched. It contains no source-event-ID retrieval index, source record text or labels. A better result here would challenge any attribution of source association specifically to FlyWire.

The usage protection modifies local synaptic update amplitude and thus the **effective learning gain**. Matching the same count of presentations and eligible original edge slots does **not** match total gradient/synaptic weight-change magnitude. Report both source retention and newest-event acquisition; do not call retention an improvement if later memories can no longer be learned. The purpose is interference versus plasticity, not demonstrating a fully fair equal-magnitude comparison.

## Outcomes and exclusion rules

At every stage, exactly the same **317 source target content vectors** are provided to an *EXTERNAL evaluation-only ranking oracle*. A neural model's only inference input is a literal cue; its output is a signed 256D numerical source-content feature vector. Nothing at model inference can inspect source narrative, record ID, target codebook or previous results.

Evaluate the exact first 16 source-record identities throughout (source-correct event top-1 and correct-source cosine margin), the newest 16 trained records (must avoid locking out new learning), the learned subset of the immutable previous 159 source positives, and the learned subset of 31 original genuinely untrained literal fourth-cue cases. Check the same never-imprinted 71 episode-absent queries at every stage. Report all group denominators and paired per-event trajectories, correct-and-accepted with **unchanged prior Pilot08 scalar threshold 0.0082783** and known-vs-absent external diagnostic AUROC without post-hoc calibration. A model that never activates on an unseen cue cannot be credited for semantic transfer. Any novel-cue correctness must be compared to deranged and non-neural baselines and eventually independently written paraphrases.

**Primary success criterion:** improve first-16 correct identities and average own-versus-best-competing content cosine margin after all 317 source memories **relative to the original baseline** while retaining reasonable newest-16 correct IDs and source-train-positive correctness. **Failure:** source-protected arms preserve early memories but markedly suppress newer learning, shuffled controls perform comparably, or the original graph offers no benefit over rewired/linear controls. These source/probe cases have been reused in prior exploratory analyses, so any measured result is a **mechanistic development result**, not an independent confirmatory accuracy claim.
