# Pilot17 — Chamber of Echoes: Allocated Episodic Memory and Competitive Routing

**Protocol committed before measuring Pilot17.** Source owner [Pretorius-Connectome](https://github.com/Azimn/Pretorius-Connectome), cumulative research [Issue #17](https://github.com/Azimn/Pretorius-Connectome/issues/17), cross-project [Artificial-Life-Research-Journal](https://github.com/Azimn/Artificial-Life-Research-Journal). Prospective design after actual [Pilot16 real source report](../results/imprinting/PILOT16_REAL_MNEMOSYNE_RESULTS.md), [full original case data](../results/imprinting/runs/flywire-pilot16-mnemosyne-run38025454741.json), and complete ten archived learned numeric checkpoints.

## Hypothesis and distinct research category

Previous Pilots08–16 learned **shared numerical weights** from each cue to a compressed 256D source-content target. Pilot16's original entire-FlyWire-v783 source run was genuine and successful but its very best density/learning-rule intervention identified just **28/159 familiar trained cue records, 7/16 newest records, 3/16 earliest records, 1/31 previously never-trained fourth original literal cues**. Its input-covariance not-known threshold correctly identified **4/159 familiar**, but falsely accepted **9/71** truly absent. A stronger pretrained language input did not improve source true-content binding on a fly-derived sparse matrix. None of those results establishes a fly-specific biological learning rule or a trustworthy autobiographical character memory.

**New hypothesis:** The binding/interference bottleneck could be relieved by allocating one independent small numeric episodic trace per actual training event, *with competitively routed semantic cues rather than a shared overloaded weight matrix*. Based on [Pan et al., complementary learning systems with sparse episodic traces (2026)](https://www.biorxiv.org/content/10.64898/2026.08.24.746712v1.full), [HiCL sparse expert gating (2025)](https://arxiv.org/abs/2508.16651), [Neural Pattern Separation and Completion (2025)](https://arxiv.org/abs/2507.11393), and [open-world novelty detection (2025)](https://www.sciencedirect.com/science/article/pii/S0004370224001735). These publications are motivations only, NOT replicated methods or transferable evidence. The intervention here has no replay, new neural physiology or detailed Kenyon-cell substrate.

**Architectural category is deliberately different:** `Chamber of Echoes` is an **EXTERNAL numerical episodic key-value memory**. It directly stores a numeric source-content target codeword for EACH original source autobiographical event and searches its learned compact cue keys at inference. Source event IDs and narrative texts are NOT stored in it, and source event identity is still assigned in an EXTERNAL fixed-317-candidate offline evaluator, but claiming this is a neural-only FlyWire learning result would be **false**. Retrieval of original stored codewords is expected to improve old literal training cue performance, and does NOT itself establish autonomous recollection, internal event truth or semantic adaptation. This architecture tests a different pathway relevant to Pretorius's future modular cognitive substrate.

## Exact predeclared frozen source and computational controls

Keep canonical original fictional v12 **450 reconstructed first-person Pretorius source events across 27 episodes**, original L0/L1 source ID/text equality, original pinned BC01 256D signed source-narrative content target SHA `65ae81401a17ec68adc3900395f226734618be4ffb2bae24745d989bd2a17625`. Seed31 episode-isolated 317 trained source records, 62 validation-episode absent, 71 test-episode absent, original fixed 159 trained-positive source cue probes, 31 original genuinely never-presented fourth cue cases. The last 159/31/71 have been inspected across prior pilots, so all findings on them are **exploratory, not an independent confirmatory test**. Keep original seed20261008 317-event training order; 3 original first/middle/last authored source cue texts; fixed stages **0,16,32,64,128,256,317**. External 317-source-event original target codebook remains CONSTANT through stages; event IDs never enter memory inference.

Reuse exact frozen source-independent [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) ONNX source revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41` and previously validated original actual file SHA `6fd5d72fe4589f189f8ebc006442dbb529bb7ce38f8082112682524616046452`; source sentence embedding projects deterministically to signed 256D from Pilot12. Then a **fixed label-independent random orthogonal 256→64 projection** (seed17031) compresses each of the three source cues. Every episode allocates **3×64 float32 source-key scalars** and one **256-dimensional float32 source CONTENT codeword**, directly original normalized BC01 top-32. No recording source text, event ID, metadata or independent target key in model, but it **does store source CONTENT vectors** and thus performs external memory retrieval, by design.

**Precise numerical memory budget:** 317×(3×64+256)=**142,016 float32 stored source key/value scalar slots**, or **568,064 bytes**. Plus one fixed precomputed 256×64 float32 label-independent projection = **16,384 additional fixed parameters, 65,536 bytes**, for **633,600 total allocated model array bytes**, excluding pretrained MiniLM model/tokenizer, numpy container overhead and the external scorer. Unrestricted Pilot16 RLS used 65,536×float32 W plus 65,536×float64 P = **786,432 learned-state array bytes** (plus its frozen pretrained MiniLM), but the two designs have different memory access, retrieval compute and source-episode allocation semantics. We disclose this byte difference, not a perfectly matched computational causal comparison.

## Five equal-storage predeclared conditions

Every arm stores the exact same numerical slot-array shapes and bytes; all source literal cues and content target vectors are identical except the deliberately deranged control.

1. `semantic_competitive_three_keys`: three separate compact semantic keys retained per event, compare each cue with all source slots, use maximum of three cosine match scores per event, **winner-takes-one stored source content codeword** at inference. THIS is the primary intervention.
2. `semantic_centroid_same_bytes`: original same three keys/slot and same exact memory storage, but combine each episode's three keys into a single normalized centroid for retrieval. This tests key competition versus a simpler average.
3. `semantic_soft_top3_same_bytes`: exact same three source keys and stored values but softmax-route top three event slots at fixed temperature **0.12** (chosen before measurement); weighted-sum signed source CONTENT and normalize. Tests winner-take-one versus content mixture.
4. `lexical_competitive_three_keys`: same 3×64 source key geometry and storage, same competitive retrieval, original **stateless BC01 lexical** cue instead of pretrained semantic MiniLM. Isolates whether pretrained semantic cue geometry improves novel source wording.
5. `semantic_competitive_wrong_content`: exact same semantic keys, wrong original source CONTENT codeword rotated by the old deterministic non-self 317-event permutation (same as Pilots13–16). Must do poorly on source identification; tests whether correct source-label binding matters rather than just pretrained cue geometry.

The primary comparison also includes **prior original full-v783 Pilot16 unmasked ridge and best dense lexical masked RLS**, using their permanently archived original raw cases as historical controls, with explicit caution that a newly allocated external content-codeword memory and shared learned-weight readouts are not representation-equivalent. Never silently characterize the external memory as original fly-derived synaptic circuitry.

## Evaluation, success gates, novelty and falsification

At every cumulative source load, score exact earliest 16 source event IDs, newest 16, known source originals among fixed 159, original 31 fourth genuinely **never trained** source literals among learned events, and 71 episode-absent queries. Report **correct target minus strongest competing target cosine margin**, correct original event top1 assigned by external fixed-317 source-content target matrix, source event and stage, internal best numeric key cosine and true output activity. A trained literal cue may be recognized 159/159 by explicit key storage and cannot be presented as semantic generalization. Most important are source fourth-cue identification and absent-episode rejection, and correct AND accepted count together.

**Native novelty score:** maximum compact semantic key cosine over all already-stored actual numeric event keys (external memory directly knows the keys, as designed); no source event labels or external target-codebook ranking. Fit threshold once at final source load on only **62 validation-episode-absent** source cues aiming ≤6 false accepts there, report threshold and acceptance on 158 non-evaluation trained source-positive calibration cues, and then independently **REPORT** positive correct-and-accepted original 159 familiar/31 fourth source cues and false accepted original 71 absents without retuning. This source heldout test has been reused in old pilots and is not a sealed new confirmation. Unlike neural input-covariance novelty, this score is directly tied to the model's explicit stored source-key memory.

**Preregistered metrics to evaluate and potentially falsify:** top1 31 fourth source cue recovery above old **1/31** weak Pilot16 result; source test 71-absent rejection at not catastrophic familiar/novel correct-and-accepted rates; old/new 16 continuity; source-content true-versus-competitor margin; competitive key routing versus equal-storage centroid and top3 blend; lexical input and wrong-content controls; actual source numeric array bytes and MiniLM provenance. If trained cues improve but fourth-source retrieval stays at 0–1/31, or true-absent false accepts remain high, **do not call this a successful semantic memory architecture**. Improvement from direct codeword retrieval is expected; any gain over learned weights is not evidence for a specific Drosophila network or synaptic plasticity. A future genuinely independent human-authored semantic paraphrase/absence battery is required before generalization claims.
