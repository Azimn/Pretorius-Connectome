# Pilot18 — Mirror Keys: Train-Only Metric and Genuine Withheld-View Recall

**PREDECLARED BEFORE SOURCE-RESULT EVALUATION.** Repository: [Pretorius-Connectome](https://github.com/Azimn/Pretorius-Connectome); original source [Pilot17 complete results](../results/imprinting/PILOT17_REAL_SOURCE_EPISODIC_RESULTS.md), permanently archived original source [five-model case JSON](../results/imprinting/runs/pilot17-episodic-source-run38029031790.json), complete research journal [Pilot17](https://github.com/Azimn/Artificial-Life-Research-Journal/blob/main/journal/2026/2026-10-10-echo-chamber-episodic-routing.md).

## Rationale and separation of representation from trivial exact-key recall

Pilot17 proved that external allocated numeric source memory resists overwriting *previously stored literal cue strings*—149/159 familiar semantic, 151/159 lexical—but **only 1/31 fourth original untrained literal cues** were correctly recovered, which also occurred in a deliberately wrong-source-CONTENT negative control. A complete source-preserving external episode-index is NOT a fly synaptic network and matching stored literal keys is not semantic generalization. Our current question is whether a small learned metric improves retrieval when the **test cue itself is absent from every training source key**.

Literature-informed mechanism: contrasting same-experience view pairs with different-experience cue negatives supports discriminative metric learning (complementary learning systems, sparse competitive hippocampal-style retrieval, supervised contrastive learning). The implemented pilot is an **analytic between-class scatter minus within-class scatter metric** fitted from two source cue views per original episode, not neural SGD triplet-loss training or anatomical Kenyon-cell circuitry. The method maximizes separation between learned original source event means while penalizing variation within each episode's two learned source cues; its top 64 orthogonal eigendirections comprise a single **256×64 float32** semantic address projection. It may fail or overfit. No advantage is assumed.

## Original corpus, *genuinely new intervention holdout*, and limits of independence

Exact same **450 fictional Pretorius source memories / 27 original episodes**, locked source L0/L1 and BC01 signed 256D CONTENT vectors, original seed31 317 train/62 episode-validation absent/71 episode-test absent, original 159 familiar probes and 31 previously examined never-trained source fourth cue cases, local frozen original [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) model/revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`, ONNX SHA `6fd5d72fe4589f189f8ebc006442dbb529bb7ce38f8082112682524616046452`, original BC01 artifact SHA `65ae81401a17ec68adc3900395f226734618be4ffb2bae24745d989bd2a17625`.

**Change exactly one experimental dimension:** each of all 317 originally selected train records contributes **ONLY first and middle original source-authored literal cues** for fitting the semantic address mapping and allocating an external memory episode. All true distinct original LAST literal cues are excluded from projection training and **never stored as keys**. The old source function has **two records with only two literal surfaces**; their third cue was previously duplicated from the middle cue: those and any duplicate-string cases are excluded from the true unseen third-view metric, not misrepresented as new. The newly withheld source-authored third-cue cohort will be counted exactly from actual original source data. Its membership is fixed without performance tuning.

This is a **new training/holdout split inside an existing source corpus**, not an independently authored sealed human paraphrase battery. The old third cues have been used in prior pilots; they are nevertheless genuinely unpresented to the Pilot18 numeric key store and metric fit, so the paired-source-view contrast is informative but exploratory. Original fourth source literals and 71 absent episode cases stay wholly excluded from metric fitting and rejection-threshold selection; cannot be counted as new untouched confirmatory evidence. No independent human paraphrase creation is claimed.

All 317 original train episodes contribute first+middle cue encodings to a *single offline global metric fit* BEFORE constructing episodic stores. This is transductive with respect to chronological intermediate stages; consequently **ONLY final 317 memory-load outcomes** are reported. No false claim of incremental online metric learning or intermediate continual learning capability.

## Six fixed source-controlled equal-byte numeric episodic arms

Every model stores source episode content as an original signed BC01 top-32 content codeword, two active 64D cue keys and a **ZERO, excluded third key slot** within the same fixed total shape as Pilot17 (317×[3×64 cue+256 content] float32 plus one 256×64 projection). All six allocated array budgets are **633,600 bytes**, including 65,536 projection bytes. MiniLM/tokenizer, array metadata, original source L1 storage and offline event-ID oracle are excluded consistently. Models DO store ORIGINAL CONTENT vectors explicitly; these are EXTERNAL memory stores, **not** end-to-end learned fly neurons. The original 317 event candidate codeword matrix and event-ID scores exist ONLY in the offline external evaluation; no source names are stored inside the model.

1. `semantic_random_two_views`: frozen MiniLM 256D semantic cue, original Pilot17 fixed random orthogonal 256×64 projection, only FIRST+MIDDLE stored. Main **same-bytes plain cosine kNN competitor**.
2. `semantic_pair_discriminant_two_views`: same frozen semantic input and stored cues, train a **linear supervised contrastive-scatter** address metric exclusively on 317 source first/middle pairs: `B=covariance(event two-cue midpoints), W=covariance(pair differences), eig_top64(B−2.0·W+0.002 I)`. Pair positives are same event; negatives represented by B as between-event scatter (not explicit sampled hard-negative triplets). Fit uses NO source content target codewords, third/fourth/absent texts or outcome correctness. Sign of each eigenvector is deterministic, seed17031.
3. `semantic_mispaired_discriminant_two_views`: **wrong same-event positive pairing** train-only control: same FIRST embeddings, permute the 317 SECOND embeddings by fixed independent seed18031 to form pseudoevents, fit exactly the same 64D discriminant projection, but store the **correct** original cue keys/content afterward. If true within-event metric matters, this should underperform correctly paired metric.
4. `semantic_pca_two_views`: unsupervised PCA top64 projection from the same 634 first/middle original source cue vectors; same stored keys/array bytes. Tests whether any gains are just train-domain covariance adaptation.
5. `lexical_random_two_views`: original stateless lexical BC01 encoder, Pilot17 random 64D projection, same first/middle source cues and storage bytes. Assesses pretrained semantic geometry against lexical source-form matching.
6. `semantic_pair_discriminant_wrong_content`: exactly the same correctly paired fitted semantic projection and stored original first/middle key views, but wrong original source target CONTENT in each numeric episode slot from the original non-self 317-record rotation. Must score source-event identity poorly.

No parameter or confidence thresholds tuned after examining heldout original third/fourth/absent outcomes. These are fixed predeclared arms, not a post-hoc model search.

## Metrics, novelty and success criteria

At **final 317 trained** source event slots only, report individual source event-ID and source true-content minus strongest-other-codeword target margins for: (a) **all eligible distinct withheld third original literal source views** (primary novel-surface outcome), (b) old 159 familiar source FIRST training cues (in-sample control), (c) old reused genuinely not trained fourth source literals of 31 eligible events (exploratory, secondary), (d) first 16 and newest 16 distinct withheld LAST cues (old/new allocation check), and (e) 71 entire never-trained episode-absent prompts. Source correctness comes from **EXTERNAL** 317-target source candidate codewords; retrieval internally searches numeric stored source keys and directly returns the chosen episode's stored content codeword.

Model-native absence confidence = maximum stored-key cosine **only over the TWO active trained key positions per episode**; zero third slots never count as keys. Choose one final acceptance threshold per arm from **62 validation-episode-absent** probes ONLY to allow at most 6/62 validation false accepts. Compare correctly-identified-AND-accepted true unseen third views, correctly accepted already-stored first views, correctly accepted reused fourth views, and falsely accepted 71 truly absent episodes **together**. Low false accepts purchased by rejecting all true novelty are a FAILED novelty mechanism.

**Scientific go/no-go:** The discriminant should improve withheld-third source event ID accuracy over the equal-byte random kNN, unsupervised PCA, and mispaired-positive metric. It should meaningfully improve correctly accepted withheld-third cues while avoiding a disproportionate increase in absent-episode false acceptance. Incorrect-CONTENT control should fail. If it only improves trained-first literal exact matches, or third-view correct/accepted remains poor, it did not solve novel-language addressing. Stronger early/late retained source IDs alone cannot validate semantic generalization. This fixed corpus was repeatedly studied: a NEW independently authored blinded paraphrase + absence panel remains required for independent confirmation, along with multiple source split seeds and additional memory-size controls. Better evaluation before promotion into Pretorius production cognition.
