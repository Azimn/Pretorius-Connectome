## Rationale, not post-hoc β tuning

Pilot14 on the actual full FlyWire-v783 learned numerical overlay demonstrated a stability/plasticity tradeoff. At 317 source autobiographical events, original single-trace baseline identified **4/16** of the first 16 and **2/16** newest source events; β=4 protected original edges identified **10/16** old but **0/16** newest. The independently learned **50,920-trainable-scalar masked non-neural matrix** identified **7/16** old, **6/16** newest and **46/159** familiar old probe IDs versus β=4's 36/159. All scored **0/31** previously untrained fourth source cues, and accepted too many of 71 truly episode-absent cases. The next intervention cannot be described as a solved memory unless it maintains early AND newly taught source associations simultaneously.

## The two-timescale model and its resource cost

A new **SLOW STABLE** trace uses Pilot14's original-edge usage-dependent metaplastic law `increment/(1+β·number_of_previous_writes)`. A separate **FAST PLASTIC** trace uses the untouched additive original signed synaptic update, with its own source-bound numerical edge-weight array. Both operate only on the exact same existing anatomical source-to-readout directed pairs; model-only inference combines the individually normalized slow and fast 256D signed responses using fixed **60% slow/40% fast**, and normalizes the combined vector. Per original source event, both traces train on its exact same three source literal cues. After all three presentations, the fast trace alone decays numerically **0.97 per completed source event**, with no external event-ID lookup. Total nominal per-cue source update rate **0.7/3 is split** 60%/40% across slow/fast traces. This is NOT the same gradient/update-norm budget as Pilot14; explicitly report total raw edge-update operations, summed weight magnitudes and changed original edge positions.

**CRITICAL capacity disclosure:** two distinct learned float32 arrays allocate **2 × 50,920 = 101,840 independent eligible scalar numeric source-edge trace slots**, plus slow local exposure counters (not in the 101,840). The intervention doubles numerical trainable storage even though it uses the *same* original anatomical edges. The control must therefore include an equally two-trace **101,840 independent scalar slot nonneural associative map**, as well as the prior 50,920-slot single-line comparator. Do not ascribe a capacity-driven gain uniquely to synaptic consolidation, fly morphology or biology. Neither doubled source/traces nor fixed source masks are the original complete biological connectome acting as a language model. The fast-trace decay is a toy engineered mechanism, not biological rehearsal, dopamine or experiential memory.

The two linear baselines have no source event-ID retrieval cache, event storage or external source target book inside inference. Shuffled-content arm must score source identity poorly or it challenges causal learning claims.

## What counts as success / failure

At every stage report full per-event source ID, source-correct outcome, original true-target minus best competing target cosine margin, source activation, fixed historical acceptance threshold 0.0082783, diagnostic full source known-vs-absent AUROC, learned numeric direct-edge delta support and update operations. Keep source ID and codebook strictly in EXTERNAL evaluator, and persist exact complete source rows and numeric checkpoints. The terminal original additive condition must reproduce **exact original frozen Pilot10 checkpoint SHA and all 159 familiar / 71 absent source case decisions**, allowing only separately labeled maximum absolute 5e-7 source float32 roundoff, never changing a source event classification.

**Primary joint metric:** pair first 16 learned source events (**old**) against the most recently trained 16 (**new**) at all loads, not just early retention. A dual trace is worth additional study only if both early and newly taught original source IDs and correct-target margins improve over original additive and Pilot14 β=4 (or at least substantially reduce the β4 acquisition collapse). Favor no added output if the new-event gain is offset by major loss of old events, much worse false acceptance, shuffled source parity or superior double-slot nonneural performance. Always disclose that 2× stored learned state may explain any improvement. **Unseen fourth source literal cues and 71 episode-absent evaluations must be reported**, even if outcomes are still 0/31 and high false accepts. This program needs genuinely independently written semantic probes and a learned internal content readout before interpreting results as semantic autobiographical continuity.
