# Shared Pretorius memory L1: executed interoperability result

**Date:** 2026-10-08  
**Status:** verified portable source representation with two working consumer paths. **This is an L1 source interface only, not a portable L2 neural feature or learned-weight cache.**

The canonical owner remains `Azimn/Pretorius-Connectome`. Its verified original corpus is `memories/current/Pretorius_v12_450_Events_Complete.jsonl`, Git blob `718dcc2d5ba4feccdef1690d447edfcebaa9bfb5`. Exactly **450** reconstructed fictional memories across **27** episodes were exported, in unchanged chronological order. Original L0 text is never rewritten in place.

## Real executed tests

**Canonical/FlyWire execution:** [Shared Pretorius L1 workflow 37839291647](https://github.com/Azimn/Pretorius-Connectome/actions/runs/37839291647) succeeded. It ran complete-export source integrity tests, deterministic repeated gzip and manifest equality, deliberate corruption and manifest-mismatch rejection, and the unchanged existing `load_v12` sidecar alignment. The existing `scripts/run_associative_memory.py` accepted the shared L1 archive through opt-in `--shared-l1` / `--shared-manifest` flags; its synthetic graph query JSON matched the original source-based query byte-for-byte. Existing benchmark defaults remain unchanged.

**BioCircuit BC01 execution:** [BioCircuit shared-input workflow 37839516626](https://github.com/Azimn/Pretorius-Neural-Network/actions/runs/37839516626) succeeded. All **16 tests** passed. The source-pinned original 450-event BC01 and portable-L1 BC01 demos were run under equal **256-neuron, seed 1842, 8-exposure** conditions; their reported `tests` arrays matched exactly. This is an engineering parity result, not a scientifically validated retrieval or persona improvement. BioCircuit's consumer pins the complete source and normalized artifact Git/SHA identities and rejects modifications.

**No L2 vector interchange claimed:** BioCircuit uses signed hashed lexical sensory encodings (256 sensory dimensions plus other input channels). FlyWire's word/bigram TF-IDF and topology projection use a different fitted feature space and different dimensions. Reusing a common source corpus does not magically make the learned weights, sensory vectors or synaptic transitions interchangeable. In particular, existing FlyWire v783 CSR original synapse counts remain unchanged.

## Reproduction

```sh
python scripts/export_shared_memory_l1.py --output-dir artifacts/shared_memory/v1
python -m unittest discover -s tests -p 'test_shared_memory.py' -v
OPENBLAS_NUM_THREADS=1 python scripts/run_associative_memory.py --synthetic-test --query "millstream map and turned glove" --shared-l1 artifacts/shared_memory/v1/pretorius_l1_v1.jsonl.gz --shared-manifest artifacts/shared_memory/v1/manifest.json
```

For the second consumer, see `Azimn/Pretorius-Neural-Network/biocircuit/shared_memory_adapter.py` and `scripts/demo_biocircuit_bc01.py` plus its CI workflow. The latter uses a pinned source repository checkout to avoid accidental changes to the shared artifact.

## Remaining issue scope

The [cross-project tracking issue #10](https://github.com/Azimn/Pretorius-Connectome/issues/10) should keep L2 split-pinned feature caching, source-versus-cache time/memory benchmark, and genuinely independent evaluations **open**. Only a deterministic encoder with identical code, feature dimensions, fit-event IDs, training split and query preprocessing can share one L2 cache. Do not export or fit TF-IDF on all 450 records and then claim that episodes are held out. The current L1 package is a verified engineering deliverable, not evidence that biological fly wiring improves autobiographical memory.
