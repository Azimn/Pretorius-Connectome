## New primary holdout: withhold third original source-authored cue

Each of all 317 trained source memories contributed exactly **two original source literal cue surfaces** (first/middle) to training of the 64D projection and to its stored numeric episode keys. The third key positions were forcibly zero and EXCLUDED from similarity retrieval; neither projection fitting nor episode memory saw last-source cue text. **316/317** original training memories have a truly distinct third original literal that can be measured as a new view; the sole non-distinct two-cue case was excluded rather than falsely counted as unseen. This is new holdout **within the old repeatedly studied corpus**, not a new independently authored sealed test set. Since the metric learned from all 317 training source cue pairs, only final-memory-load results can be interpreted without transductive future-cue exposure.

## What this experiment actually falsifies and what it does not

A simple **global 256→64 discriminant address adapter trained on same-memory first+middle cue pairs** did **not** rescue the source's third original authored wording. Its source recall was **0/316**, identical to the random semantic baseline, worse than unsupervised PCA's accidental **1/316** and lexical's accidental **2/316**; the deliberately wrong-CONTENT control even matched **3/316** by chance. Neither the pretrained sentence encoder nor a simple train-only pair-scatter linear metric learned meaningful generalization across these source cue surfaces in this configuration. These exact numerical results falsify a strong positive interpretation of this particular metric, **not all possible metric learning or episodic memory systems**. Source provenance, independently written prose, contextual search/reasoning, and actual subject memory trust remain open problems.

**Critical source corpus caveat:** source records may contain cue surfaces not written as semantic paraphrases of one another; this has not yet been proved or disproved by an independent human semantic equivalence annotation. The original BC01 CONTENT target is a compressed numeric lexical representation, so a decoded correct event ID in an EXTERNAL 317-target oracle is not autobiographical natural-language recall. The 316 third cues were withheld **in this new experiment**, but many were trained in prior pilots and this corpus has been inspected many times; do not report this as independent generalization evidence. The misleading 3/316 in the wrong-content control quantifies chance in this fixed 317-way event-ID scorer and is useful as a negative baseline.

**Research next gate (not retrospectively adjusted here):** audit the *actual semantic equivalence, distinctness, and lexical overlap* of all original source cue surfaces using predeclared rules and independent annotation, BEFORE designing another metric learning experiment. Then build an independently authored blinded paraphrase set with trust/provenance and absent-content controls; test content-guided retrieval or hybrid keyword + semantic recall against equal-storage plain retrieval, without accessing evaluation text for training. Do not tune the 64D rank, pair penalty 2.0, regularization .002, cue types or confidence gate on the observed 316/31/71 outcomes.
