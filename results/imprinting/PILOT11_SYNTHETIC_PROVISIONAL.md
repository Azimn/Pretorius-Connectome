# Pilot11 synthetic source-cue transfer and validation-only rejection: provisional baseline

**Status: synthetic topology only, not a FlyWire biological result.** Original full source-linked 450-event and 27-episode canonical autobiography and BC01 lexical encoder used with a generated 8192-neuron, 16-degree numerical graph. All original graph arrays were left unchanged and the synthetic source-specific learned checkpoint was replayed without retraining. Exact [source Actions run 37870200081](https://github.com/Azimn/Pretorius-Connectome/actions/runs/37870200081) passed both unit/source guards and full synthetic smoke, producing the original complete per-case JSON in artifact flywire-pilot11-SYNTHETIC-only.

The frozen Pilot10 experimental exposure and calibration schedule were reproduced: seed-31 split of 317 training events, 158 non-test positive calibration cases, 159 test positives, 62 validation-absent calibration and 71 episode-absent test cases.

| Test | Original threshold | Validation-selected rejection gate |
|---|---:|---:|
| Correctly accepted familiar-cue test memories (N=159) | 8/159 (5.03%) | 1/159 (0.63%) |
| False acceptance of absent test episodes (N=71) | 62/71 (87.32%) | 8/71 (11.27%) |
| Correctly identified truly unseen fourth literal source cue (N=31 eligible) | 0/31 | 0/31 |
| Correctly identified trained last cue on same eligible 31 | 3/31 (9.68%) | 0/31 |

The 31 eligible unseen fourth-cue source cases were **never among the three explicit cue presentations** in Pilot10. **30/31** activated no common top-8 signed BC01 lexical feature coordinate with any of their own three originally trained cues. These are separate source recall surfaces, not independently validated semantic paraphrases.

The empirical validation-only acceptance threshold was **0.63683065**, selected from 158 positive train-case calibration prompts and 62 validation-episode absent prompts. It allowed exactly 6/62 false accepts in validation, constrained to at most 10%. The 71 absent test episodes were untouched during selection. The decrease in false accepts comes with very poor correct-and-accepted recall, not a solution to memory reliability.

These are preliminary, nonbiological source-linked computational findings. They are **not** proof of anything about real FlyWire topology. The original publisher-checksum-pinned 139,255-neuron and 15,091,983-edge real biological Pilot11 verification is separately running, and the full per-case evidence must be permanently archived when green.

An external oracle codebook supplies the event-ID match; the frozen synaptic overlay itself accepts only a cue string and returns a 256D lexical vector. No autonomous autobiographical memory, semantic embedding transfer, fly physiological plasticity or first-person persona is established.
