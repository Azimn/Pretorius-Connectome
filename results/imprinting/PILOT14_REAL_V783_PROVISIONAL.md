## Source and historical neural provenance

The experiment consumes the original version-pinned **450 reconstructed fictional autobiographical Pretorius events across 27 episodes**, original source-aligned BC01 256D lexical input and original signed BC01 256D narrative content target vectors, the seed31 317-event train/62-validation-episode-absent/71-test-episode-absent split, source first/middle/last literal cue exposures and fixed original neural cue-and-content feature populations. Full original **publisher-verified FlyWire v783** contains 139,255 root IDs, 15,091,983 aggregate directed neuron pairs and 54,492,922 integer synaptic contacts; all four original CSR array checksums and original anatomy remain unchanged.

The exact 50,920 original existing directed synaptic source/readout eligible slots are available in all original-graph neural arms. The binary-degree-preserving rewired null exchanged **49,962** original eligible directed destinations in an independent control graph, preserving each eligible source outdegree/readout target indegree and total original source contact counts; it does *not* preserve each target's contact-weighted incoming strength. The nonneural parameter-count control has **exactly 50,920 learnable scalar input-to-output matrix slots**, but does **not** match connection geometry, biological weights, update norms, numeric compute budget or contact multiplicity.

**The terminal original additive arm replayed the actual frozen Pilot10 learned float32 synaptic state bit-for-bit**: 951 source cue presentations; 28,938 nonzero original-edge deltas; identical entire array with zero difference; identical 159 historical source-positive and 71 historical absent-episode event predictions; original historical frozen checkpoint SHA-256 `fbc2f329993d414cde3ce3a1271a1083098c6513410373e124362045a427c86a`. This real run therefore passes a strictly stronger historical parity check than the predeclared allowable 5×10⁻⁷ roundoff bound.

**Primary preregistered old-vs-new trade-off:** the original β=4 arm doubled-plus its early remembered source IDs (4→10) while losing the last two correctly identified **newest** events of the original baseline (2→0). β=1 retained 8 old IDs and 1 newly taught ID. Rewired β=1 retained 11 old IDs but **0 newly taught IDs**. Thus metaplastic protection is a *partial improvement in early-source retention*, NOT a solved ongoing memory system. The β=1 and β=4 mechanisms necessarily change the effective signed update magnitude, so they are **not same-gain** controls despite the same 951 presentations and original eligible anatomical support.

**Important external nonneural comparator:** a fixed seeded 50,920-trainable-scalar-slot 256×256 masked linear cue-to-content weight map obtained **46/159 familiar event IDs and 6/16 new source IDs** after 317 events, outperforming every FlyWire source graph arm on new-memory acquisition and familiar recall, though it preserved fewer early events than original β=4 or rewired β=1. The linear model does not use a source event-ID retrieval index or source texts at inference, and also failed 0/31 true source fourth-cue transfer. Its source-aligned mask is count-matched, not fully matched on graph structure or effective update magnitudes. This supports continued investigation of representation, routing and plasticity without inferring that actual FlyWire is intrinsically superior.

**False acceptance persists:** the unchanged historical source similarity threshold (0.0082783) falsely accepted 52–60 of 71 completely episode-absent probes across arms. No model establishes robust detection of unfamiliar biographical content, autonomous event-label decoding, natural language narrative recall, real fly plasticity learning rules or cross-model persona continuity. All models scored **0/31** on completely untrained fourth original source literal cue probes.

## Mechanistic conclusion and explicit next scientific gate

On source-verified actual fly-directed synapse support, exposure-dependent local numerical write attenuation reduces original early-event association loss. The effect generalizes to rewired source-derived controls, while a simple external-content-free matched-slot learned linear comparator retains more newly taught events. This suggests the remaining bottleneck is **balancing stable and plastic association without a source-event lookup**, in addition to lack of source-semantic cue transfer.

A prospective **Pilot15** should therefore independently preregister balanced rehearsal, an adaptive local synaptic write rule or compartmental/competitive feature routing, and a learned *internal vector readout*, while preserving an adequate equal-capacity non-neural trained mapping, source-correct versus deranged labels, old/young cohort recall, full source 159/71/31 tests, and a prospective independently reviewed semantic cue set. Preserve Pilot14 outcomes as frozen negative/partial evidence, not post-hoc parameters to tune.
