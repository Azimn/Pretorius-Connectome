**Reproduced baseline:** The source BC01 original biological graph condition reproduced the original Pilot10 20/159 familiar last-cue results and 71 absent-episode original cases, thereby passing independent historical replay within the same split and neural source signature.

**Representation insight:** With the original BC01 hashed lexical encoder, **30 of 31** never-trained fourth literal cues had *no shared top-8 selected input coordinates with any of their own three trained source cues*. With the frozen local MiniLM sentence encoder and fixed 384→256 projection, only **5 of 31** had no shared selected feature coordinates. Yet all six models still recovered **zero** correct fourth-cue event IDs. Thus overlap improved but association identity did not: geometry and representation input sharing are not sufficient for this one-hop learning/readout architecture. We cannot infer the pretrained model universally fails at semantics; its projected top-8 signal and fixed source-feature mapping may discard discriminating cues, and the short gothic source cue strings may be ambiguous.

**Topology insight:** Under source-matched BC01 lexical cues, original real FlyWire achieved 20/159 familiar event matches and its binary-degree-preserving rewired null achieved 21/159. The pretrained MiniLM original achieved 0/159, rewired achieved 1/159. **No advantage of original fly wiring over this matched-null support is detected.** These are correlated source probes under one seed and not independent replications; the null does not preserve contact-weighted target incoming strength or final learned plastic weight density exactly, so this is not a universal negative biological-connectivity theorem.

**Rejection limitation:** Gate thresholds calibrated on separate training and validation records constrain empirical false acceptance on their validation partition, not on independent test episodes. The original BC01 comparator reduced 71-test absent false acceptance to 5/71 but kept **0/159** correctly accepted familiar events. Rewired lexical retained only 2/159 correctly accepted; MiniLM models retained zero. Low false-acceptance alone **does not create reliable memory.**

## Direct scientific conclusion

These controlled results show **limited learned cue-linked content signal on actual original FlyWire-directed synaptic slots**, but the signal is not demonstrably attributable to fly-specific wiring, does not transfer to truly unseen source cues, and is not rescued by plugging in a pretrained semantic encoder. The pretrained input supplies an **external model prior**; target narrative contents are still fixed signed BC01 hashes; the model-only output is a 256D numerical vector. Only an *external oracle* maps it back to original source event IDs. There is no autonomous reconstructed autobiography, biological STDP, semantic subjective recollection or definitive Pretorius.

This is a useful **causal null**, consistent with source-specific synaptic capacity and interference, sharply reduced discriminability caused by top-8 sparse 256D input projection, and/or output decoder information bottleneck. Disentangling these requires a new named experiment, not tuning Pilot12 after the fact. Next recommended controls: (1) measure per-event source-content margin and readout rank with the original learned state; (2) compare a frozen semantic encoder with richer continuous input activation or learned associative cue router without an external event-ID retriever; (3) match contact-weighted target strength in biological rewiring and multiple seeds; (4) hold out independently written and reviewed semantic cue prompts.
