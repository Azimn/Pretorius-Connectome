# Pilot14 synthetic-only numerical synaptic stability: complete preliminary finding

**Source:** [successful original source-owned GitHub Actions synthetic test 37882541412](https://github.com/Azimn/Pretorius-Connectome/actions/runs/37882541412), [pinned seven-arm preregistration](../../docs/FLYWIRE_DIRECT_IMPRINT_PILOT14.md), full uploaded original case-level JSON and actual learned numerical NPZ checkpoints in artifact pilot14-SYNTHETIC-only-seven-arms. **This graph is artificial, not original biological FlyWire evidence.** It contains 8192 generated neurons, unique aggregated directed pairs and original fictitious Pretorius L1 450-event BC01 source.

Each condition learned identical original first/middle/last literal source cue events from the same training-order sequence at cutoffs 0,16,32,64,128,256,317, with fixed full 317-event **EXTERNAL** target-codebook ranking at all stages. All source content matches the same canonical reconstructed autobiography. The seven arms separate original learning, binary-degree-rewired original *synthetic* support, β=1 and β=4 source-neural numerical exposure-dependent write protection, wrong-content β=1 source control and a non-neural source-independent scalar-slot-count-matched masked 256×256 linear matrix.

**Interpretation: a bounded negative result.** In the generated nonbiological graph, heavier local edge-usage protection can make earlier source-event IDs more persistent relative to the original additive rule, and the real/rewired paired controls expose the same effect. **But it does not produce useful new-event learning under accumulated memory load**: every original-graph condition correctly identified **0 of its newest 16** source memories at full training, and the old fixed similarity acceptance rule still falsely accepts approximately 60–65/71 never-imprinted source episodes. All tested models identify 0/31 of the original fourth literal source cues. A generic nonneural mapping also loses most initial source associations, showing that source codeword overlap/interference is not uniquely fly-shaped.

Protected edge exposure counters are *numerical per-directed-synapse training state*, not external autobiographical event lookup, source-specific key/routing or independently validated biological Drosophila plasticity. The control holds event count, training presentations, lexical inputs, external content codebook and number of eligible scalar parameter slots, **not net signed gain/weight norms**: β protection intentionally attenuates later learning. Results therefore cannot establish a beneficial plasticity/retention trade-off without balancing early and newly learned source recall.

The real original publisher-verified whole FlyWire-v783 seven-arm assay is a **separate required verification gate**, not interchangeable with this synthetic result. Its source anatomical arrays must remain intact, with comparison to historical original Pilot10 159-positive/71-absent per-case predictions, signed checkpoint SHA and explicit float32 roundoff bounds.
