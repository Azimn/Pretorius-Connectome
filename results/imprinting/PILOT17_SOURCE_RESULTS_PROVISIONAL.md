## Result is an architectural diagnostic, not a generalization breakthrough

**The distinct episode allocation mechanism succeeds at preventing catastrophic familiar-cue forgetting within this explicit external numeric retrieval architecture:** the very same initially added original 16 source episodes remain 16/16 correctly retrievable after 317 learned episodes with competitive semantic or lexical routing; newest16 15/16, versus only 3 earliest / 7 newest under the previous best Pilot16 original dense lexical residual shared-weight condition. The previous Pilot16 best scored 28/159 familiar literal trained source IDs; this one scores 149/159 in semantic competitive mode. **However, the models are NOT representation- or access-equivalent.** Pilot17 directly stores 317 separate original CONTENT codewords and all 3 exact original training cue keys in an external numeric memory store. Retrieving the correct codeword given an *identical training cue* is expected, is **not demonstrated semantic paraphrase recall**, and cannot be attributed to original full 139,255-neuron FlyWire v783 biology or any learned synaptic consolidation.

**Genuinely new source wording is still the bottleneck.** Even with frozen pretrained MiniLM semantic source cue embeddings, competitive and soft-top3 routing identify just **1/31** original never-trained fourth literal source cues. Importantly the deliberately WRONG-CONTENT source control also scores **1/31** by coincidence, demonstrating that this 1/31 does not establish a genuine event-specific semantic transfer effect. The **lexical** baseline gets **0/31**. The old 31 have been repeatedly inspected in previous pilots; neither is an independently sealed blinded paraphrase panel. On this evidence a successful human-style subject-generalizing episodic memory has **NOT** been built.

**Open-world source absence also remains unresolved:** competitive semantic key-similarity novelty was threshold-calibrated using only 62 validation source-absent events with <=6 empirical validation false positives (the old 159/31/71 evaluation records did not set threshold), then tested on heldout absent71. It correctly identified and accepted 149/159 *training literal familiar cues*, but also **falsely accepted 15/71** entirely absent episodes and accepted **0/31 correctly retrieved genuinely never-trained fourth source cues**. The more conservative centroid accepts 10/71 absent falsely but retains only 54/159 correctly accepted familiar. The native key gate is not useful for new semantic cues even if it performs well on familiar exact training surfaces.

### Byte budget and claims

All five models have exactly **142,016 mutable/stored float32 scalars** (317×(3×64 cue +256 CONTENT)), **568,064 bytes**, plus fixed **16,384 scalar/65,536-byte random source cue projection** = **633,600 bytes of model numeric arrays**. The previous original source unmasked Pilot16 ridge model allocated **65,536 float32 W +65,536 float64 P =786,432 bytes**, though these are NOT structurally equivalent architectures. Frozen public MiniLM encoder weights and tokenizer/storage overhead are not included in either memory comparison. The episodic model explicitly stores the actual source CONTENT vector per episode; unlike the old learned-weight model, it relies on external episodic record allocation and search. It never stores event-ID labels or narrative text in its numeric representation, but that does NOT make it a purely distributed neural model.

The scientific next gate is **train-only learned semantic key metric alignment** (positive cues originally attached to same 317 events, negatives from others) or independently reviewed new semantic paraphrases, with strict heldout fourth original cue/absent episode reporting, and *matched resource* competitive routing versus ordinary kNN/centroid alternatives. Do NOT retroactively tune the 31 already-observed source fourth cues. Source event provenance and trust needs its own mechanism; confidence based only on maximum key similarity still rejects genuinely novel wording and accepts unrelated source cues.
