## Meaning of 1/31 genuinely untrained source cues

The dense lexical-BC01 masked RLS, dense MiniLM masked RLS, random-feature mask and dense unrestricted nonneural RLS each produced **exactly 1/31** correct fourth original source event ID, compared with 0/31 in original additive. One identification across 317 candidate memories is compatible with chance and these exact 31 source cues were examined exploratorily across Pilots11–15; **this does not establish generalizable semantic autobiographical recall**. An independently written, prospectively sealed cue battery and new random seeds are indispensable.

## Novelty gate is still inadequate

Cue-only input covariance `F(x)=clip(1−xᵀPx,0,1)` was threshold-calibrated ONLY on the original 62 validation-episode-absent cases, aiming <=6 false accepts there, with the original heldout 71 absent, original 159 familiar and repeated fourth source 31 excluded from threshold tuning. The leading lexical-source-RLS model correctly identified AND accepted just **4/159** familiar cases, yet falsely accepted **9/71** truly absent cases; unrestricted MiniLM correctly accepted 3/159 familiar yet falsely accepted 12/71 absent. A threshold that rejects almost everything is NOT an improvement in trustworthy memory. Wrong-content RLS identified 1/159 by chance and incorrectly accepted that source case. No model learns a native natural-language memory validator here.

## Interpretation and prospective next causal gate

An **online prediction-error correction rule** is promising for initial same-cue source content association and newer-item acquisition relative to naive Hebbian superposition; pretrained semantic cue vectors alone do not solve the source-to-CONTENT mapping bottleneck. More critically, the source recurrent original graph is not a directly simulated brain in Mnemosyne, but a binary 256×256 feature-pair **STRUCTURAL PRIOR** derived from real FlyWire directed connectivity. It stores no event IDs, natural-language source archive or full biological neuronal dynamics.

The current program needs **separately allocated episode learning with competitive routing, balanced per-episode storage and rehearsal/consolidation**; compare with a source-archive kNN/RAG retrieval system openly labeled as an external-memory system, and with an **equal-bit-budget** conventional associative baseline. Do not secretly smuggle that index into a neural-only condition. A new prospective independently authored source-unseen paraphrase set and external-source provenance guard must precede tuning. Evaluate old/new source recalls, signed margins, independently authored cue recovery and true absent rejection on the SAME new evaluation split. Do not declare a positive biological FlyWire architectural advantage until original-specific wiring materially beats biological rewire and equal-capacity nonneural controls.
