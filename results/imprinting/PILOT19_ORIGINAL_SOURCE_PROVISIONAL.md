The real graph and exact index produced **identical performance** on all original source third cue queries: **287 correctly attributed, 29 ambiguously shared cues where attribution must abstain**, no graph-specific accuracy gain. That control is decisive against any claim that traversal independently improved source cue accuracy. The wrong-owner control returned **0/316 correct original event IDs**, confirming that *correctly assigned cue-to-event edges* were responsible rather than superficial cue-label matching. It explicitly retained mismatched original source owner provenance for audit.

### Index exposure changes the meaning of the test

This experiment separated six information availability conditions. First+middle source-cue-only indexing excluded the original third cue and scored **0/316**. Conversely all-sidecar exact and graph arms stored **316/316** original third literal cue surface forms, so their **287/316** success is expected lookup of source information that the system was explicitly permitted to store. This is evidence for **correctly bound event-detail indexing and provenance**, not learning that two unrelated English phrases are semantically synonymous, nor recovering a never-observed cue by reasoning.

Narrative-only BM25 indexed the full source `memory_text` but not annotations; the third cue surface appeared verbatim in only **75 of these 316 TRAIN events**, yet it retrieved **121/316** events correctly (69 correct-and-accepted at the validation-only operating point). Further 46 correct matches may derive from shared partial query tokens or contextual lexical matches; those cases cannot be credited to semantic inference absent additional evidence. The comparison with flat BM25 is **NOT matched evidence/storage**, whereas exact sidecar vs graph IS matched.

Original sidecars are **entirely unreviewed**; “green tape” candidate may be indexable but is not confirmed perception or accepted autobiography. Each returned relation carries an original source event ID, annotation field, annotation status, original details, plus participants and locations for the graph. An absent query is not a reliable “false memory” validation without independent adjudication, even though all 71 source records were withheld from indexing. Exact index and graph falsely accepted **6/71** absent episode cues, so source ownership alone does not solve truth, duplicate cue collisions or subject access. Validation thresholds were calibrated exclusively on 62 separate episode-absent cases to allow at most six, not selected against the 316 third/71 test results. No post-hoc graph weights or BM25 hyperparameters were tuned.

## Scientific interpretation and forward requirement

**Positive narrow result:** a persistent, source-bound connection from `candidate detail` to `event` to `other candidate detail` is a functional, auditable event association mechanism, and its explicit provenance permits refusal on ambiguous ownership. The best exact-index/graph precision over 316 original third-cue queries is not evidence of a cognitive advantage over a simpler exact index. Source association by **stored evidence** is useful for a future Pretorius memory substrate, provided annotation review and Synthetic Ipseity subject-access controls are applied before any memory becomes trusted first-person experience.

**Next gated research:** independently review candidate anchors against source prose and classify supported/unsupported details; add a **separate source-provenance rejection battery** with deliberately wrong-event and absent claims; then commission independently authored, sealed human-verified paraphrase and counterfactual distractor queries. The latter test must NEVER include those exact new strings in an indexed sidecar or training cue; report honestly what it accesses. Do not conflate lexical cue presence, source event association, relationship graph traversal, and semantic paraphrase transfer.
