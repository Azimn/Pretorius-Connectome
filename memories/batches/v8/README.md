The canonical-for-this-project integrated narrative is `The_Autobiography_of_Doctor_Septimus_Pretorius_Master_v8.md`. The imprintable records are `Pretorius_v8_337_Events_Complete.jsonl`; the added incremental set is `Pretorius_v8_50_New_Events.jsonl`. Reconstruction is integrated autobiography for the fictional subject. Provenance and source research are external metadata and are not a rule that memories should feel any less real during imprinting. No biological connectome experiment is claimed to have been run by this writing batch.
