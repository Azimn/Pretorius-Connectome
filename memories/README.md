All **400 previous v10 event IDs, dates, titles and first-person texts remain unchanged** in v11. The fifteen E26 memories introduced by the v10 400-record milestone have not been replaced. Only chronological_order numbers were reallocated after inserting E25. V10, v9, v8 and v7 complete snapshots remain in [current](current/); the [v10 master](current/The_Autobiography_of_Doctor_Septimus_Pretorius_Master_v10.md) and [v9 master](current/The_Autobiography_of_Doctor_Septimus_Pretorius_Master_v9.md) retain earlier reference apparatus.
